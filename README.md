Cloud-VM-Baseline-Reporter
The tool collects system information, validates hostname consistency, and displays listening TCP/UDP sockets for security review.

A Bash-based baseline inventory tool for Linux virtual machines
and cloud server environments.

## Features
- Collects current user and hostname
- Collects date and system uptime
- Checks expected hostname consistency
- Displays listening TCP/UDP sockets
- Produces a readable terminal report

## Technologies
Bash, Linux, Vim, ss
